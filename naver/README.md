# 네이버 블로그 반자동 발행

- 매일 글 발행 루틴이 사이트 새 글을 바탕으로 네이버 블로그용 초안을 `naver/drafts/YYYY-MM-DD-<slug>.md`에 만들어 둡니다.
- 사용자는 주 1~2회 https://blog.naver.com/moneycalc5 에 로그인해 초안을 복사해 붙여넣고 발행합니다. 글당 3분.
- 초안 형식: 첫 줄 제목, 그다음 본문(문단 단위, 표는 텍스트로), 마지막에 링크 1개와 태그.
- 올린 초안은 `naver/posted.md`에 날짜와 제목을 한 줄 적어 두면 루틴이 중복 주제를 피합니다(적지 않아도 동작에는 문제 없음).
- 원칙: 사이트 글을 그대로 복사하지 않고 요약·재작성, 글당 외부 링크 1개, 하루 1편 이하, 광고성 표현 금지. 네이버 저품질 분류를 피하기 위한 규칙입니다.

## 발행 화면 설정 (매번 동일)
- 카테고리: 게시판 (글이 쌓이면 세분화)
- 주제: 비즈니스·경제 (반드시 지정, 네이버 노출 분류 기준)
- 공개 설정: 전체공개
- 발행 설정: 댓글허용, 공감허용, 검색허용, 블로그/카페 공유(링크 허용), 외부 공유 허용 모두 체크
- "이 설정을 기본값으로 유지" 체크 (다음부터 자동 적용)
- 태그: 초안 마지막 줄의 태그 5개 (#첫글 같은 기본 태그는 삭제)
- 발행 시간: 현재 / 공지사항으로 등록: 체크 안 함
